# 物流运力调度系统 产品需求文档

## 1. 项目概述

### 1.1 项目背景
随着物流行业的快速发展，传统的人工调度方式已无法满足高效、智能的运力调度需求。本系统旨在通过智能化的算法和自动化流程，实现车辆、订单、司机的高效匹配，提升物流运输效率。

### 1.2 项目目标
- 实现运输订单的智能化创建与管理
- 自动匹配可用车辆与运输订单
- 优化运输路线，合并同路线订单
- 实时监控运输状态，计算预计到达时间
- 自动生成延误预警
- 统计分析车辆利用率、司机准时率、线路延误率

## 2. 功能需求

### 2.1 运输订单管理
- 创建运输订单，记录货物信息（重量、体积）
- 系统自动计算货物重量和体积需求
- 订单状态跟踪（待调度、已分配、运输中、已完成、异常）

### 2.2 车辆调度匹配
- 根据区域、车型、容量匹配可用车辆
- 同路线订单自动合并为一个运输批次
- 车辆状态管理（可用、已锁定、运输中、维护中）

### 2.3 司机接单管理
- 司机接单后系统锁定车辆和订单运输状态
- 记录装车顺序
- 运输节点更新与预计到达时间计算

### 2.4 运输监控与预警
- 运输过程中节点更新
- 超过预计时间未更新节点时自动生成延误预警
- 定时任务检测延误订单

### 2.5 异常处理
- 异常订单进入调度池
- 管理员重新安排车辆
- 异常记录与跟踪

### 2.6 统计分析
- 车辆利用率统计
- 司机准时率统计
- 线路延误率统计
- 数据可视化展示

## 3. 用户角色

| 角色 | 职责 |
|------|------|
| 管理员 | 订单管理、车辆管理、司机管理、异常处理、统计查看 |
| 司机 | 接单、更新运输节点、完成运输 |
| 调度员 | 订单调度、异常处理 |

## 4. 技术约束

- 前端框架：Vue.js
- 后端框架：SpringBoot + Java 8
- 数据存储：本地内存（暂不使用数据库）
- 后端端口：8003
- 前端端口：3003

## 5. 界面规划

### 5.1 主要页面
1. 首页/仪表盘 - 统计数据概览
2. 订单管理 - 订单列表、创建订单、订单详情
3. 车辆管理 - 车辆列表、车辆状态管理
4. 司机管理 - 司机列表、司机信息管理
5. 调度中心 - 订单调度、批次管理
6. 运输监控 - 实时运输状态、节点更新
7. 异常处理 - 异常订单列表、重新调度
8. 统计分析 - 各类统计报表

### 5.2 设计风格
- 专业商务风格，深蓝色为主色调
- 清晰的数据展示，突出关键指标
- 简洁直观的操作流程
- 响应式布局，支持桌面端使用
